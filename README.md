## 🚀 The 8 Core Sovereign Capabilities

### 1. 📝 Assignment Solver & Mathematical Proof Verifier
- **Axiomatic Grounding**: Solves problems step-by-step from fundamental theorems (Master Theorem, Coffman Deadlock Conditions, Armstrong's Axioms, Spectral Theorem, etc.).
- **KaTeX / LaTeX Formatting**: Every formula is rendered with mathematical precision.
- **Formal Proof of Invariants**: Provides inductive proofs, base-case verifications, asymptotic tight bounds ($\Theta(n \log n)$), and dimensional homogeneity checks.
- **Examiner Trap Alerts**: Automatically flags common student pitfalls that cause deduction in university exams.

### 2. 🔍 Solution Auditor, Grader & "Cheque" Engine
- **Step-by-Step Rubric Check**: Grades student drafts against standardized university schemes (Formulation, Algebraic Accuracy, Boundary Verification, Academic Presentation).
- **Edge-Case & Boundary Detection**: Flags missing base cases ($n=0, n=1$, empty sets, overflow limits).
- **Official Academic Audit Certificate**: Outputs assigned marks (e.g. `9.2/10`), percentages, university grades (`O`, `A+`, `A`), and actionable remediation notes.

### 3. 📄 Anti-AI Luxury Publication-Grade PDF Generator
- **Zero AI Clichés**: Strictly eliminates generic purple-to-indigo gradients, sterile card grids, and harsh single-drop shadows.
- **Editorial Typography**: Styled in rich obsidian (`#0F172A`) on warm alabaster/ivory (`#FAF9F6`), with hairline borders (`0.5pt`), shaded data tables, and optical tracking (`-0.02em`).
- **Academic Running Headers & Footers**: Two-pass `NumberedCanvas` generating authentic "Page X of Y" counters, course codes, and date headers.

### 4. 📐 Autonomous Vector Diagram Studio with Live Fallback Links
- **Actual Vector Graphics**: Generates real, publication-grade SVG system architectures, algorithmic flowcharts, and high-resolution Matplotlib benchmark curves.
- **Resilient Web Fallback Registry**: If a complex domain diagram (e.g., *Intel 8086 Microprocessor, Transformer Multi-Head Attention, RISC-V Pipeline, TCP 3-Way Handshake, OSI 7-Layer Stack, B+ Trees*) requires external reference, Prof. Anna embeds authenticated, direct clickable URLs to authoritative repositories (IEEE Xplore, Wikimedia Commons, arXiv, RFC specifications, W3C) so the student can inspect the exact high-definition blueprint.

### 5. 📊 PPT Reference Cloner & SIH Pitch Deck Optimizer
- **Reference Cloner**: Ingests reference slide templates, preserves exact structural balance and card geometries, and substitutes your research and project specifics.
- **Smart India Hackathon (SIH) Pattern Analyzer**: Evaluates presentations against the official AICTE / SIH jury scoring rubric (Problem Severity, Novelty & IP, Technical Architecture, Business Model, Live Prototype Demo).
- **Automated Jury Defense**: Produces a synthesized **Winning 7-Slide Pitch Deck** and a **Jury Defense Cheat Sheet** predicting tough evaluator questions with bulletproof answers.
- **Dual Export**: Outputs native 16:9 widescreen `.pptx` presentations AND self-contained, 60fps responsive HTML5 slide decks.

### 6. 📜 IEEE Access Research Paper Synthesizer
- **Two-Column Standard**: Adheres strictly to the IEEE Access / IEEE Transactions format.
- **Full Structure**: Title, Authors (Student Member IEEE), Abstract, Index Terms, Sections I–VII, formal equations, comparative feature matrices, threats to validity, and standard IEEE references.
- **Dual Formats**: Compiles production-ready LaTeX (`.tex`) and publication-grade HTML previews with KaTeX rendering.

### 7. 🎯 Exam Forensics & Pareto 80/20 Success Rate Checklist
- **PYQ Forensics**: Ingests 5-year previous year question papers across university schemes (SPPU, MU, VTU, Anna Univ, AKTU).
- **Pareto 80/20 High-Yield Filter**: Isolates the top 20% recurring concepts that historically generate 80% of total exam marks.
- **Exam Readiness Checklist**: Interactive topic mastery checklist that calculates your real-time **Predicted Exam Score %** and **Readiness Tier** (*Distinction Secured, First Class, Safe Pass*).
- **Rapid 1-Day Revision Sheet**: Essential formula sheet and compulsory derivations tracker.

### 8. 💡 Feynman Mental Models & Spaced Repetition (Anki)
- **Feynman Technique Explainer**: Translates intimidating algorithms into crystal-clear everyday physical analogies and 10-year-old child explanations.
- **Anki Spaced Repetition (SRS)**: Exports Anki-compatible `.csv` and `.tsv` flashcard decks tagged with exam recurrence probability.

## ⚡ Quickstart Guide

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/adityanimbalkar9699-max/prof-anna-study-agent.git
cd prof-anna-study-agent
pip install -e .
```

### 2. Launch Interactive Web Studio
Experience all 8 engines in a sleek, Apple-grade browser dashboard:
```bash
python -m anna.cli web
# OR
streamlit run anna/web/app.py
```

### 3. Command Line Interface (CLI) Usage

#### Solve an Assignment Problem with Formal Proof:
```bash
python -m anna.cli solve "Solve recurrence T(n) = 2T(n/2) + Theta(n)"
```

#### Audit and Grade a Student Solution ("Cheque"):
```bash
python -m anna.cli check --problem "Solve T(n) = 2T(n/2) + n" --solution "Given T(n) = 2T(n/2) + n. By Master Theorem Case 2, T(n) = Theta(n log n). Q.E.D."
```

#### Generate an Anti-AI Publication-Grade PDF:
```bash
python -m anna.cli pdf --topic "Divide and Conquer Master Theorem"
```

#### Generate Publication Diagram with Verified Fallback Link:
```bash
python -m anna.cli diagram --topic "Transformer Multi-Head Attention" --type architecture
```

#### Optimize Presentation for Smart India Hackathon (SIH):
```bash
python -m anna.cli sih --title "Autonomous Rural Water Leakage Detector" --ps "SIH-2024-PS1482"
```

#### Synthesize an IEEE Access Research Paper:
```bash
python -m anna.cli paper --topic "Edge Computing Distributed Consensus"
```

#### Run Pareto 80/20 Exam Forensics:
```bash
python -m anna.cli exam --subject "Operating Systems"
```

#### Explain a Tough Concept with Feynman Mental Models:
```bash
python -m anna.cli feynman "Deadlock"
```

#### Generate Anki Spaced Repetition Flashcards:
```bash
python -m anna.cli flashcards --subject "Operating Systems"
```
